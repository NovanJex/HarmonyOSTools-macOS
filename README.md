## 一、 适用系统与机型范围

本工具底层基于 **ADB（Android Debug Bridge）** 调试接口运行：
* ✅ **支持系统**：
  * **HarmonyOS 2.0 / 3.0 / 4.0 / 4.2**（兼容 AOSP 底座的鸿蒙系统）
  * **EMUI 9.0 ~ 11.0**（华为机型）
  * **MagicUI**（早期荣耀机型）
* ❌ **不支持系统**：
  * **HarmonyOS NEXT（5.0 及以上纯血鸿蒙）**：纯血鸿蒙已移除 AOSP 底座与 ADB 接口（改用 `hdc` 工具且包名体系完全不同），无法使用本工具。

本移植版 100% 保留了原版 `HarmonyOS.bat`（共 2,872 行代码）的全部 7 大模块与包名库：

| 模式代码 | 模块名称 | 主要功能描述 |
| :---: | :--- | :--- |
| **`m1`** | **主菜单** | 免 Root 卸载/装回高频系统内置应用（智慧搜索、智慧语音、智慧识屏、智慧建议、负一屏、华为音乐、服务中心、钱包、天际通、冗余服务、快应用、运动健康）、**开启/关闭巅峰性能模式（`-14` / `+14`）**、**禁用系统更新（`-20` / `+20`）** |
| **`m2`** | **定制模式** | 提供 `01` ~ `044` 共 44 项深度系统组件卸载与恢复（含恢复 5G 开关 `-042`）、**`000` 一键还原全部操作**、**`999` 小白安全精简交互向导** |
| **`m3`** | **监视模式** | 查看手机综合运行情况（`top`）、系统内存（`free`）、系统/第三方软件包名列表、微信/QQ/支付宝/TIM 内存占用及自定义包名内存查询（中文化输出） |
| **`m4`** | **动画模式** | 无极调节窗口动画缩放、过渡动画缩放、动画程序时长缩放倍数 |
| **`m5`** | **功能模式** | 重启到 Recovery、无极修改亮屏时间、查询/断开 ADB 设备、切换无线 ADB 调试（`5555` 端口）、状态栏图标精简隐藏、手动输入包名卸载/安装/禁用/解禁 App、批量安装文件夹内 `.apk`、强制固定屏幕高刷新率、修改系统后台白名单 |
| **`m6`** | **瘦身模式** | 深度清理微信、QQ、TIM 缓存目录、图库缩略图缓存及系统冗余日志 |
| **`help`** | **帮助模式** | 常见连接报错解答与操作指引 |

## 三、 macOS 快速开始

### 1. 手机端开启 USB 调试
1. 打开手机 **设置** -> **关于手机** -> 连续点击 7 次 **版本号** 开启开发者模式。
2. 返回 **设置** -> **系统和更新** -> **开发人员选项** -> 开启 **USB 调试**（建议同时开启“仅充电模式下允许 ADB 调试”）。
3. 用支持数据传输的数据线将手机连接到 Mac，手机下拉通知栏将 USB 连接方式改为 **传输文件 (MTP)**，并在手机弹窗中勾选 **“始终允许使用这台计算机进行调试”** 点击确定。
   *(注：macOS 原生免装驱动，无需像 Windows 一样安装驱动或手机助手)*

### 2. Mac 端启动工具箱

#### 方式一：通过 `git clone` 下载（推荐，自动保留执行权限）
```bash
git clone https://github.com/<你的用户名>/HarmonyOSTools-macOS.git
cd HarmonyOSTools-macOS
./启动鸿蒙工具箱.command
```
或者直接在 Finder（访达）中双击 **`启动鸿蒙工具箱.command`** 即可自动打开 Mac「终端」运行。

#### 方式二：直接下载 ZIP 压缩包或从 U 盘拷贝
如果从网页直接下载 ZIP 或通过 Windows U 盘拷贝到 Mac，首次双击可能会提示“没有权限打开”或安全拦截。只需打开 Mac「终端 (Terminal)」，进入本文件夹执行一次以下命令赋予权限并移除苹果隔离属性：
```bash
cd /path/to/HarmonyOSTools-macOS
chmod +x *.command adb
xattr -cr .
```
执行完成后，以后随时直接双击 **`启动鸿蒙工具箱.command`** 即可启动！
